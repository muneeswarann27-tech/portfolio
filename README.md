# Muneeswaran Portfolio

Recovered and rebuilt from the public Netlify portfolio:

https://muneesportfolios.netlify.app/

## Run Locally

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
```

Deploy the generated `dist` folder to Netlify, Vercel, GitHub Pages, or any static hosting service.

- Profile image
- Four project screenshots
- Resume PDF

The original production bundle was also downloaded into `assets/` as a recovery backup.
